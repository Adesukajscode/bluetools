## ✨ Fitur

- 🔐 **Login & Register** — session-based, password di-hash pake `password_hash()`
- ⬇️ **Download video** — YouTube, TikTok, Instagram (Reels/Post/Story)
- 🎵 **Ekstrak audio** — convert ke MP3 otomatis pake ffmpeg
- 🎨 **UI putih-biru** — responsive, clean, modern
- 🪶 **Ringan** — gak butuh Node.js, cukup PHP
- 📱 **Mobile-friendly** — dibikin buat Termux + HP
